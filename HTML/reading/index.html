Курс «HTML: за 10 уроков» / "HTML: in 10 lessons"

Курс состоит из 10 тем и посвящён языку гипертекстовой разметки HTML — от создания первой HTML-страницы до самостоятельной сборки и публикации полноценного веб-проекта. По завершении обучения студент умеет разрабатывать семантически корректные и доступные веб-страницы, а также понимает принципы взаимодействия HTML с CSS и JavaScript.

The course consists of 10 lessons dedicated to the HTML markup language — from creating your first HTML page to building and publishing a full web project. Upon completion, students can develop semantically correct and accessible web pages, and understand how HTML interacts with CSS and JavaScript.

Как проходить курс / How to study / Qanday o‘qish kerak

Русский

Для кого: для начинающих, которые умеют создавать папки, сохранять файлы и пользоваться браузером. Предыдущий опыт программирования не требуется. HTML — язык разметки; курс посвящён структуре и содержанию страниц. Самостоятельное написание CSS, JavaScript и серверного обработчика в программу не входит.

Что понадобится: компьютер, современный браузер и редактор кода. В первом уроке объясняется запуск страницы. Работайте в собственной папке, не поверх файлов примеров.

Маршрут: прочитайте объяснение → выполните мини-задание → закройте пример → выполните самостоятельную работу → пройдите критерии → ответьте на вопросы. Если критерий не выполнен, исправьте работу и повторите проверку. Задания урока N используют только уроки 1–N. Для первого прохождения изучайте уроки по порядку.

Примеры и задания: practice.html — готовый англоязычный пример для разбора, а не файл с условием задания. В уроке 10 пример состоит из четырёх страниц. Самостоятельная работа и критерии находятся в конце каждого урока; единственное решение не навязывается. Ресурсы примеров включены в папки уроков; изображения — авторские учебные иллюстрации. Формы демонстрируют проверку и GET-запрос с вымышленными данными, сообщения не доставляют.

Результат: опубликованный многостраничный HTML-сайт и способность объяснить его структуру, проверить ссылки, ресурсы и основные требования доступности. Сначала выполните разобранный проект, затем независимое итоговое задание урока 10.

Темп свободный: раздел «План урока» показывает содержание, а не обещанную длительность. Точное время зависит от самостоятельной практики. Визуальные схемы требуют поддержки Mermaid в Markdown-просмотрщике; удобное HTML-издание находится в папке reading.

English

Audience and tools: beginners who can create folders, save files and use a browser. No programming experience is required. Use a computer, a modern browser and a code editor. HTML is a markup language. Writing CSS, JavaScript or a server-side form handler is outside this course.

Study route: read → try the mini-task → close the example → complete the independent assignment → check every acceptance criterion → answer the questions. Fix unmet criteria before continuing. Assignment N uses only lessons 1–N. Work in your own folder and follow the lesson order.

Examples: practice.html is a supplied English worked example, not the assignment brief. Lesson 10 has a four-page example. Each lesson ends with an independent assignment and acceptance criteria; more than one solution is possible. Local media are supplied, and the images are original teaching illustrations. Demo forms use fictional data to show validation and a GET request; they do not deliver messages.

Outcome: a published multi-page HTML site and the ability to explain its structure and check navigation, resources and basic accessibility. Complete the guided project, then the independent assessment in lesson 10. Study at your own pace: lesson plans do not claim a fixed duration. Mermaid support is needed for diagrams in Markdown; the reading folder contains the HTML reading edition.

O‘zbekcha

Kim uchun va vositalar: papka yaratish, faylni saqlash va brauzerdan foydalanishni biladigan yangi o‘rganuvchilar uchun. Dasturlash tajribasi shart emas. Kompyuter, zamonaviy brauzer va kod muharriri kerak. HTML — belgilash tili. CSS, JavaScript yoki serverdagi forma ishlovchisini mustaqil yozish bu kursga kirmaydi.

O‘qish tartibi: tushuntirishni o‘qing → kichik topshiriqni bajaring → namunani yoping → mustaqil ishni bajaring → tayyorlik mezonlarini tekshiring → savollarga javob bering. Bajarilmagan mezonni tuzatib, qayta tekshiring. N-dars topshirig‘i faqat 1–N-darslar materialiga asoslanadi. O‘z papkangizda ishlang va darslarni ketma-ket o‘ting.

Namunalar: practice.html — ingliz tilidagi tayyor tahlil namunasi; bu topshiriq sharti emas. 10-dars namunasi to‘rt sahifadan iborat. Har bir dars oxirida mustaqil ish va tayyorlik mezonlari bor; yagona yechim talab qilinmaydi. Mahalliy media fayllar kiritilgan; rasmlar muallif yaratgan o‘quv chizmalaridir. Namuna formalarda faqat xayoliy ma’lumotlardan foydalaning: ular tekshirish va GET-so‘rovni ko‘rsatadi, xabar yetkazmaydi.

Natija: e’lon qilingan ko‘p sahifali HTML-sayt hamda uning tuzilishini tushuntirish, havolalar, resurslar va asosiy veb-dostuplilik talablarini tekshirish ko‘nikmasi. Avval yo‘naltirilgan loyihani, keyin 10-darsdagi mustaqil yakuniy ishni bajaring. Sur’at erkin; dars rejasi qat’iy davomiylikni va’da qilmaydi. Markdown chizmalari uchun Mermaid qo‘llovi kerak; reading papkasida HTML o‘qish nashri mavjud.

Итоговый проект и платформа JLearn

  • Исходный код итогового проекта: заготовки, 7 пошаговых снимков сайта, готовый сайт и образцы документов (план, чек-лист, журнал).
