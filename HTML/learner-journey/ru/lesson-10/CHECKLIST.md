# Локальный журнал итогового проекта

| Требование | Что подготовлено | Что осталось |
| --- | --- | --- |
| Четыре связанные страницы | index/meetings/resources/join, одинаковые четыре пункта меню | Фактические клики в браузере |
| Заголовки и списки | Один h1 на страницу, h2 для разделов, ul/ol по смыслу | Визуальная проверка |
| Изображение | Локальный PNG с фактическим alt и размерами 160×120, figure/figcaption | Загрузка и вид на узком экране |
| Таблица | caption, thead/tbody, col/row scope, три строки данных | Визуальная/скринридерная проверка |
| Форма | label/id, name/value, fieldset/legend, required/email/pattern/maxlength; GET помечен демонстрацией | Пустой/неправильный/правильный ввод в браузере |
| Доступность | Нативные поля и кнопки, логичный исходный порядок, никаких положительных tabindex | Tab/Shift+Tab, Enter/Space, доступные имена, контраст |
| Метаданные | Уникальные title/description, charset, viewport, CSS/JS/favicon | Network и Nu HTML Checker |
| Публикация | Подготовлены файлы и PLAN.md | Не выполнена, публичной ссылки нет |

Баллы не присвоены: полные баллы требуют наблюдаемых проверок; локальная подготовка не равна зачёту. Две конкретные проверки исходника — совпадение href с файлами и label/for с id — проверены автоматически в общем отчёте JOURNAL.md. Обнаруженные препятствия курса и их исправления перечислены там же.
