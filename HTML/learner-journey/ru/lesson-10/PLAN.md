# План самостоятельного итогового сайта

Тема — клуб внимательного чтения, не личное портфолио из образца. Четыре страницы: index (цель, правила), meetings (табличное расписание, подготовка), resources (иллюстрация и список), join (демонстрационная форма с проверкой). На всех одинаковое меню, один главный h1, main и footer. Доступность планируется через видимые подписи, логичные уровни, заголовки таблицы, смысловой alt и нативные элементы; ARIA без необходимости не добавляется. CSS/JS — готовый комплект урока9. Локальные изображения — комплект урока4 с описанием фактического содержания. Форма GET без action, никаких настоящих личных данных.

Проверки до публикации: все16 пунктов меню, ресурсы/иконки, уникальные title/description, поля и ошибки ID/email, клавиатура, мобильный экран, Nu HTML Checker. Затем отдельно создать публичный репозиторий и включить GitHub Pages по инструкции курса. Внешняя публикация в этом прохождении не выполняется.
