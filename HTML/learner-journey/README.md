# Проверочные решения и журналы

Эта папка предназначена для проверки курса преподавателем и для разбора **после самостоятельной попытки**. Это возможные решения, а не единственный допустимый ответ. Работайте над собственными заданиями в отдельной папке.

Сохранены 30 поурочных комплектов: 80 HTML-страниц, локальные ресурсы, мини-задания и ответы на вопросы. Папки уроков идут последовательно; решение N использует материал уроков 1–N. Для форм и проверки загрузки открывайте через локальный HTTP-сервер, как описано в курсе. Ссылки ниже открывают основную работу; mini.html лежит рядом там, где есть отдельное мини-задание.
