# Доказательства прохождения

Итоговый `browser-walkthrough.json` содержит 290 подтверждённых условий, включая три наблюдения нативного интерфейса из `native-select-check.json`. `headless-browser-walkthrough.json` сохраняет первоначальные три неподтверждённые попытки выбора в системном меню: это история диагностики, а не итоговые ошибки курса.

`nu-local.json` — локальная проверка всех 126 HTML-страниц без внешней загрузки. `progression-check.json` — проверка зависимостей 80 решений. `table-grid-check.json` — проверка 12 таблиц. Папка `before` содержит первоначальные изображения схем, папка `after` — исправленное отображение. Имена и состояния контролов в системном браузере подтверждены наблюдаемым деревом доступности; это не испытание настоящим скринридером.
