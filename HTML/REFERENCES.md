# Источники / References / Manbalar

Основные технические источники для проверки курса. Ссылки нужны для уточнения требований; чтение полного стандарта не является заданием для начинающего.

Primary sources used to check the course. Reading the full standard is not a beginner assignment.

Kursni tekshirish uchun asosiy texnik manbalar. Standartni to‘liq o‘qish yangi o‘rganuvchi uchun topshiriq emas.

- [WHATWG HTML Living Standard](https://html.spec.whatwg.org/multipage/) — элементы, атрибуты и поведение HTML / HTML elements, attributes and behavior / HTML elementlari, atributlari va ishlashi.
- [Text-level semantics](https://html.spec.whatwg.org/multipage/text-level-semantics.html) — `strong`, `em`, `b`, `i`.
- [Form submission attributes](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#form-submission-attributes) — `action`, `method`, GET/POST.
- [Input](https://html.spec.whatwg.org/multipage/input.html) — типы полей и ограничения / input types and constraints / maydon turlari va cheklovlar.
- [WAI tutorials](https://www.w3.org/WAI/tutorials/) — изображения, таблицы, формы / images, tables, forms / rasmlar, jadvallar, formalar.
- [WAI Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/) — клавиатурное поведение / keyboard interaction / klaviatura bilan boshqarish.
- [WCAG contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) — контраст / contrast / kontrast.
- [Google Search: snippets](https://developers.google.com/search/docs/appearance/snippet) — описание страницы / page descriptions / sahifa tavsifi.
- [GitHub Pages: creating a site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) — публикация / publishing / nashr qilish.

GitHub может менять подписи интерфейса. При расхождении используйте официальную инструкцию, сохраняя общий порядок: загрузить файлы → выбрать источник Pages → дождаться успешной публикации → проверить публичную ссылку.

GitHub may change interface labels. Follow the official guide if labels differ: upload files → select the Pages source → wait for a successful deployment → test the public URL.

GitHub interfeys yozuvlarini o‘zgartirishi mumkin. Farq bo‘lsa, rasmiy yo‘riqnomaga amal qiling: fayllarni yuklash → Pages manbasini tanlash → muvaffaqiyatli nashrni kutish → ochiq URLni tekshirish.

- [Nu HTML Checker: official local distribution](https://validator.github.io/validator/) — локальная проверка без загрузки файлов / local checks without uploading files / fayllarni yubormasdan mahalliy tekshirish.
