# Обновление издания

Исходники курса — Markdown в папках уроков. Готовое издание `reading/index.html` открывается без установки инструментов и без интернета.

Для редактора: установите Python-зависимости из `requirements.txt` и выполните `python3 tools/build_reading.py`. Если изменились схемы, установите Node-зависимости в папке tools, установите Chromium для Playwright и выполните `node tools/render_diagrams.cjs`. Затем выполните `python3 tools/check_course.py`.

При использовании уже установленного браузера можно передать его путь через `JLEARN_BROWSER`. Рендер проверяет синтаксис всех Mermaid-схем и сохраняет локальные SVG; код самих схем не исполняется как JavaScript. После изменения структуры уроков обязательна ручная проверка зависимостей заданий по `COURSE_MAP.md`.

CSS/JS из папки Lesson-9 предоставлены ученику готовыми. Инструменты из этой папки служат редактору курса и не входят в задания учеников.

Дополнительная проверка: `python3 tools/check_learner_progression.py` проверяет сохранённые ученические работы. Для браузерного прогона запустите локальный HTTP-сервер в корне курса и передайте его адрес через `JLEARN_BASE_URL` при запуске `node tools/check_learner_browser.cjs`. По умолчанию используется http://127.0.0.1:8843. Результаты пишутся в learner-journey/evidence. Проверка выбора в системном меню может потребовать настоящего интерфейса macOS; прежнее подтверждение используется только при совпадении хеша проверенного файла.

Nu выполнялся автономной официальной сборкой во временной папке. Сама сборка не включена в курс; повторную локальную проверку можно выполнить официальным vnu, указав корень курса и режим skip-non-html. Отправка учебных файлов во внешний валидатор не требуется для работы инструментов редактора.
