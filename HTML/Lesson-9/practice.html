Example: Meta Tags and Project Structure

Project Structure


my-website/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   └── hero-photo.jpg
└── favicon.png

This is a supplied CSS/JS connection example. Writing these files is not an assignment. Add og:url and og:image only after you have actual public HTTPS URLs.

Path Examples

CSS in head: <link rel="stylesheet" href="css/style.css">

JS in head: <script src="js/main.js" defer></script>

Favicon: <link rel="icon" href="favicon.png">

Image: <img src="images/hero-photo.jpg" alt="...">
