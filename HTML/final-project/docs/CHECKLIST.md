# Чек-лист перед публикацией

Отметьте каждый пункт для **каждой** страницы.

## Структура

- [ ] Один `<h1>`, уровни заголовков без пропусков.
- [ ] `header`, `nav`, `main`, `footer` на своих местах, `main` один.
- [ ] Меню одинаковое на всех страницах, все 16 переходов (4 × 4) работают.

## Содержание

- [ ] У каждой картинки `alt` по её содержанию или `alt=""` для украшений.
- [ ] Таблица - только для данных, есть `caption` и `scope`.
- [ ] У каждого поля формы связанная подпись, кнопка `type="submit"`.
- [ ] Текст ссылок объясняет, куда они ведут.

## Метаданные

- [ ] `charset`, `viewport`, свой `title` и свой `description` на каждой странице.
- [ ] CSS и JS подключены, в Network нет 404.

## Доступность

- [ ] Вся страница проходится Tab и Shift+Tab, фокус виден.
- [ ] Ссылка пропуска меню переводит в `main`.
- [ ] У ссылок-иконок есть `aria-label`.

## Проверка

- [ ] Nu HTML Checker: ошибок нет.
- [ ] Страница читается в режиме телефона в DevTools.
- [ ] После публикации открыта публичная ссылка и проверены все переходы ещё раз.
