# Итоговый проект: портфолио Азиза

Исходный код учебного проекта урока 10. Сайт из четырёх страниц собирается за 7 шагов, по одному на каждый раздел «Пошаговая сборка» урока.

## Как пользоваться

1. Возьмите свою тему и начните с папки `starter/` (пустые заготовки четырёх страниц).
2. Выполните шаг урока на своём сайте.
3. Сравните результат с папкой этого шага в `steps/`. Не копируйте: сравнивайте и объясняйте разницу.
4. Готовый сайт - в папке `final/`. Он совпадает с последним шагом.

Каждая папка шага - полный рабочий сайт: её можно открыть через Live Server.

## Шаги

| Папка | Что добавлено |
| --- | --- |
| `steps/01-skeleton` | Скелет: header, nav, main, footer |
| `steps/02-content` | Контент: заголовки, текст, списки |
| `steps/03-media` | Медиа: изображения, figure, favicon |
| `steps/04-table` | Таблица способов связи |
| `steps/05-form` | Форма обратной связи |
| `steps/06-meta` | Метатеги, CSS и JS |
| `steps/07-a11y` | Доступность: ссылка пропуска, aria-label |

## Что важно в этом проекте

- Все пути относительные: папку можно перенести или опубликовать на GitHub Pages без изменений.
- У каждой картинки свой `alt`, который описывает то, что на ней нарисовано.
- Почта, телефон и Telegram - вымышленные (`example.com`, `+998 90 111-22-33`).
- Форма учебная: `method="get"`, данные никуда не доставляются.
- CSS и JS готовые (урок 9), писать их не требуется.

## Документы проекта

В папке `docs/` - образцы документов, которые сдаются вместе с итоговой работой:

- `PLAN.md` - карта сайта и план страниц;
- `CHECKLIST.md` - чек-лист перед публикацией;
- `JOURNAL.md` - журнал проверок.

Все картинки - учебные иллюстрации, созданные для курса.
