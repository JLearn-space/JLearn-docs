# Источники / References / Manbalar

Основные технические источники для проверки курса. Ссылки нужны для уточнения деталей; чтение полной спецификации не является заданием для начинающего.

Primary sources used to check the course. Reading the full specification is not a beginner assignment.

Kursni tekshirish uchun asosiy texnik manbalar. Spetsifikatsiyani to‘liq o‘qish yangi o‘rganuvchi uchun topshiriq emas.

## Спецификации / Specifications / Spetsifikatsiyalar

- [W3C: CSS current work](https://www.w3.org/Style/CSS/current-work) — список всех модулей CSS и их статус / all CSS modules and their status / barcha CSS modullari va ularning holati.
- [CSS Cascading and Inheritance Level 5](https://www.w3.org/TR/css-cascade-5/) — каскад, специфичность, наследование, урок 2 / lesson 2 / 2-dars.
- [Selectors Level 4](https://www.w3.org/TR/selectors-4/) — селекторы, псевдоклассы, уроки 2 и 9 / lessons 2 and 9 / 2- va 9-darslar.
- [CSS Color Module Level 4](https://www.w3.org/TR/css-color-4/) — `hex`, `rgb()`, `hsl()`, прозрачность, урок 3 / lesson 3 / 3-dars.
- [CSS Flexible Box Layout Module Level 1](https://www.w3.org/TR/css-flexbox-1/) — урок 5 / lesson 5 / 5-dars.
- [CSS Grid Layout Module Level 2](https://www.w3.org/TR/css-grid-2/) — урок 6 / lesson 6 / 6-dars.

## Доступность и проверка / Accessibility and checking / Qulaylik va tekshiruv

- [WebAIM: Contrast Checker](https://webaim.org/resources/contrastchecker/) — проверка пары «текст - фон» / check a text-background pair / «matn - fon» juftini tekshirish.
- [Nu HTML Checker](https://validator.w3.org/nu/) — проверка с отметкой CSS, урок 10 / check with the CSS option, lesson 10 / CSS belgisi bilan tekshiruv, 10-dars.
