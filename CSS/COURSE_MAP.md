# Карта курса CSS

В задании урока N используются только понятия из уроков 1–N и курса HTML.

| Урок | Новые понятия | Задание в IDE | Опирается на |
| --- | --- | --- | --- |
| 1. Подключение и синтаксис | Три способа подключения; правило, селектор, свойство, значение; группа селекторов; комментарии; DevTools → Styles | Первая стилизация: `body`, группа `h1, h2`, `p`, комментарий | Курс HTML: `<link>`, `<head>`, пути |
| 2. Селекторы и каскад | Классы; тег, класс, `id`, `*`; потомок, ребёнок, сосед, атрибут; каскад, специфичность, порядок; наследование; почему не `!important` | Новости кружка: `.card`, `.card.featured`, `nav a`, `ul > li` | 1 |
| 3. Цвет, единицы, шрифты, фон | `hex`, `rgb()`, `hsl()`, прозрачность; контраст; `px`, `rem`, `em`, `%`, `vw/vh`; `font-*`, `line-height`, `text-*`; Google Fonts; фон: цвет, картинка, градиент | Шапка с градиентом, шрифты в `rem`, полупрозрачный фон | 1–2 |
| 4. Box model | `padding`, `border`, `margin`, короткая запись; схлопывание; `box-sizing`; `max-width` и `margin: 0 auto`; `display`; `border-radius`, `box-shadow` | Карточки и кнопка-ссылка | 1–3 |
| 5. Flexbox | Контейнер и элементы; оси; `justify-content`, `align-items`; `gap`, `flex-wrap`; `flex`; `align-self`, `order` | Шапка и ряд карточек | 1–4 |
| 6. Grid | `display: grid`; `fr`, `repeat()`; `auto-fit` + `minmax()`; `span`; `grid-template-areas`; Flexbox или Grid | Макет страницы и галерея | 1–5 |
| 7. Позиционирование | `static`, `relative`, `absolute`, `fixed`, `sticky`; `inset`; `z-index`; `scroll-padding-top` | Липкая шапка, значок, кнопка «Наверх» | 1–6 |
| 8. Адаптивность | `viewport`; mobile-first; `@media (min-width)`; точки перелома; резиновые картинки; `clamp()`; `prefers-color-scheme` | Адаптивная страница 1 → 2 → 3 колонки | 1–7 |
| 9. Состояния и движение | Переменные; псевдоклассы; `:focus-visible`; псевдоэлементы; `transition`; `transform`; `@keyframes`; `prefers-reduced-motion: no-preference` | Живой интерфейс | 1–8 |
| 10. Итоговый проект | Слои файла стилей; оформление семантических тегов; проверка перед публикацией; обновление GitHub Pages | Оформление страницы контактов своего сайта | Все |

## Принципы курса

- Внешний файл стилей; `<style>` - только для заданий в IDE.
- Оформление через классы и семантические теги; `!important` и `style=""` не используются.
- Шрифты в `rem`, первым правилом - `box-sizing: border-box`.
- Mobile-first, медиазапросы через `min-width`.
- Фокус клавиатуры никогда не убирается: оформляется через `:focus-visible`.
- Движение - только внутри `@media (prefers-reduced-motion: no-preference)`.
- Стиль записи: `свойство: значение;`, отступ 4 пробела. Так код проверяет IDE.

## Практика на платформе

Задание в IDE - один HTML-файл со стилями в `<style>`, серверная статическая проверка. Многостраничная работа, режим устройства, клавиатура и публикация - в части «Проект на компьютере». Подробно - [platform/README.md](platform/README.md).
