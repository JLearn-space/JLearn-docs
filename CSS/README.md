# Курс «CSS: за 10 уроков» / "CSS: in 10 lessons"

> Курс из **10 уроков** о каскадных таблицах стилей: от подключения первого файла до полного оформления и публикации сайта. После курса студент оформляет адаптивные страницы с Flexbox и Grid, поддерживает тёмную тему и делает доступные состояния и анимации.
>
> A **10-lesson** course on CSS: from linking the first stylesheet to fully styling and publishing a website.

## Перед началом

Нужен курс [«HTML: за 10 уроков»](https://github.com/JLearn-space/HTML): итоговый проект CSS оформляет сайт из итогового проекта HTML.

**Как проходить урок:** прочитайте объяснение → выполните мини-задания → сделайте задание в IDE на платформе → проект на компьютере → тест урока. Урок засчитывается, когда сданы задание в IDE и тест от 70%.
