# Итоговый проект курса CSS: портфолио Азиза

Берём готовый сайт из итогового проекта курса «HTML за 10 уроков» и полностью оформляем его одним файлом `css/style.css`. HTML почти не меняется: добавлены только класс `skip-link` у ссылки пропуска меню и обёртка `<div class="cards">` вокруг проектов.

## Как пользоваться

1. Начните с папки `starter/`: сайт без стилей, пустой `css/style.css`.
2. Выполните шаг урока 10 на своём сайте.
3. Сравните свой `style.css` с файлом этого шага в `steps/`. Не копируйте: сравнивайте и объясняйте разницу.
4. Готовый сайт - в `final/`.

## Шаги

| Папка | Что добавлено |
| --- | --- |
| `steps/01-base` | Основа: переменные, box-sizing, шрифт, цвета, контейнер |
| `steps/02-layout` | Раскладка: шапка на Flexbox, сетка проектов на Grid |
| `steps/03-components` | Компоненты: карточки, таблица, форма, кнопки |
| `steps/04-responsive` | Адаптивность: mobile-first и медиазапросы |
| `steps/05-states` | Состояния и движение: hover, focus-visible, переходы, анимация |

## Что важно в этом проекте

- Mobile-first: базовые стили для телефона, медиазапросы `min-width`.
- Все цвета в переменных: тёмная тема - это просто другие значения переменных.
- Фокус клавиатуры виден на всех ссылках, кнопках и полях.
- Анимации выключаются при настройке «уменьшить движение».
- Сайт без классов почти везде: оформление по семантическим тегам из курса HTML.
