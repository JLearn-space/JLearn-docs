# Задания IDE и тесты курса CSS для JLearn

По одному файлу на урок: `lesson-01.json` … `lesson-10.json`. В каждом - задание для IDE в конце урока и тест на 12 вопросов.

## Как устроены задания по CSS

Задание - один HTML-файл, стили пишутся в `<style>`. Проверка та же, что в курсе HTML: серверный статический разбор (`language: "html"`). Свойства CSS ищутся как подстроки, поэтому в курсе закреплён единый стиль записи: `свойство: значение;` - двоеточие сразу после свойства, один пробел, точка с запятой. Об этом говорится в уроке 1 и в подсказках каждого задания.

## Структура файла

```json
{
  "lesson": 1,
  "lesson_title": "...",
  "task": {
    "title": "Название задания",
    "language": "html",
    "description": "Условие для ученика",
    "starter_code": "Стартовый код в редакторе",
    "rules": { "...": "правила HtmlTaskChecker" },
    "hints": ["Подсказки, если проверка не прошла"],
    "solution": "Эталонное решение (для преподавателя)",
    "wrong_solutions": [{"mistake": "...", "code": "..."}]
  },
  "test": {
    "pass_percent": 70,
    "questions": [ ... 12 вопросов ... ]
  }
}
```

### Правила (`task.rules`)

Используются только ключи, которые уже поддерживает `HtmlTaskChecker`:

| Ключ | Формат в файлах |
| --- | --- |
| `required` | Список подстрок. `<!DOCTYPE html>` проверяется как декларация |
| `forbidden` | Список подстрок |
| `tags` | `{"тег": минимальное число}` |
| `attrs` | `{"тег": ["атрибут", ...]}` - хотя бы у одного элемента |
| `text` | Список строк видимого текста |
| `h1_exact` | Число |
| `h2_required` | Минимальное число `h2` |
| `for_id_pairs` | `true` |
| `scope_values` | `["col", "row"]` |
| `button_submit` | `true` |
| `empty_link_a11y` | `true` |
| `href_targets` | Список точных значений `href` |
| `input_types` | Список типов `input` |

Если в `coding_tasks.rules` у вас другая форма значений (например, `h2_required` хранится иначе), поправьте при импорте только форму - состав правил менять не нужно.

### Вопросы (`test.questions`)

| `type` | Поля |
| --- | --- |
| `single` | `options`, `answer` - индекс верного варианта с 0 |
| `multiple` | `options`, `answer` - список индексов (минимум 2) |
| `matching` | `pairs` - список пар `[левое, правое]` |
| `input` | `answers` - допустимые ответы, `case_sensitive: false` |

У каждого вопроса есть `explanation` - пояснение после ответа.


## Языки

| Папка | Язык |
| --- | --- |
| `platform/lesson-NN.json` | русский |
| `platform/uz/lesson-NN.json` | узбекский (латиница) |
| `platform/en/lesson-NN.json` | английский |

В каждом файле есть поле `"language": "ru" | "uz" | "en"`. Переведено всё, что видит ученик: название и условие задания, стартовый код, подсказки, эталон, ошибочные решения и 12 вопросов теста.

Правила проверки в CSS-курсе не зависят от языка: они проверяют селекторы и свойства. Единственное отличие - урок 10: в `forbidden` узбекской и английской версий добавлено `aziz`, чтобы не принималась копия образца. Набор ключей правил, типы и порядок вопросов, индексы верных ответов совпадают во всех трёх языках - эмулятор это проверяет.

## Как проверено

`tools/check_platform_tasks.py` повторяет серверную проверку (вырезает комментарии, разбирает разметку libxml, ничего не выполняет) и для каждого урока подтверждает:

- эталонное решение **проходит** все правила;
- стартовый код **не проходит**;
- каждое типичное ошибочное решение из `wrong_solutions` **не проходит**;
- в тесте 12 вопросов всех четырёх типов, ответы указаны корректно.

Запуск: `python3 tools/check_platform_tasks.py` (нужен `lxml`). Результат - в `platform/platform-check.json`.

## Что статическая проверка не ловит

Это остаётся в части «Проект на компьютере» каждого урока:

- как страница выглядит на разной ширине экрана (уроки 5–8, 10);
- применяется ли правило на самом деле: проверка видит, что правило написано, но не считает каскад;
- CSS-комментарии не вырезаются: свойство внутри `/* */` засчитается;
- контраст цветов, видимость фокуса, эмуляция настроек пользователя (уроки 3, 8, 9);
- публикация на GitHub Pages (урок 10).

## Что не выкладывать ученикам

Поля `solution` и `wrong_solutions` в этих JSON - только для преподавателя.
