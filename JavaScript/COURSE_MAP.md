# Карта курса JavaScript

В задании урока N используются только понятия из уроков 1–N и курсов HTML и CSS.

| Урок | Новые понятия | Задание в IDE | Опирается на |
| --- | --- | --- | --- |
| 1. Первая программа | Что делает JavaScript на странице; консоль DevTools; `<script src defer>`; `console.log`; инструкция и `;`; комментарии `//` и `/* */`; переменные `let` и `const`; правила имён; ошибки в консоли | Карточка ученика: переменные `const` и `let`, изменение значения, вывод в консоль | Курс HTML: `<script>`, пути к файлам |
| 2. Типы и операторы | `number`, `string`, `boolean`, `null`, `undefined`; `typeof`; арифметика и `%`; шаблонные строки; `Number()`, `String()`, `NaN`; сравнение `===` и `!==` | Чек покупки: сумма, скидка, итог шаблонной строкой | 1 |
| 3. Условия | `if` / `else if` / `else`; `&&`, `\|\|`, `!`; truthy и falsy; тернарный оператор; `switch` | Оценка по баллам и проверка возраста | 1–2 |
| 4. Циклы | `for`, `while`; `break`, `continue`; счётчик и накопитель; `for...of` по строке; бесконечный цикл и как его остановить | Таблица умножения и сумма чётных чисел | 1–3 |

## Принципы курса

- Код подключается внешним файлом: `<script src="js/main.js" defer></script>`. Встроенный `<script>` - только в заданиях IDE.
- Переменные объявляются через `const`, а `let` - только если значение меняется. `var` не используется.
- Сравнение - только `===` и `!==`.
- Текст на страницу выводится через `textContent`. `innerHTML` с данными пользователя не используется.
- Обработчики событий - через `addEventListener`; атрибуты `onclick=""` не используются.
- Внешний вид меняется классами CSS (`classList`), а не через `element.style`.
- Стиль записи: отступ 4 пробела, `;` в конце инструкции, имена в `camelCase`, строки в двойных кавычках. Так код проверяет IDE.

## Практика на платформе

Задание в IDE - один JavaScript-файл. Платформа запускает код ученика в песочнице и проверяет результат автоматическими тестами: значения переменных, результаты функций, вывод в консоль, состояние DOM. Многостраничная работа, отладка в DevTools и публикация - в части «Проект на компьютере». Подробно - [platform/README.md](platform/README.md).
