## Зачем это вам

У интернет-магазина сотни товаров, у каждого - название, цена, категория, наличие. Заводить переменные `product1Name`, `product1Price`, `product2Name`... невозможно. Данные хранят в **массивах** (списки) и **объектах** (карточки со свойствами). Почти всё, что сайт получает с сервера, - массив объектов.

После этого урока вы сможете: посчитать средний балл класса, найти товар по названию, отобрать всех отличников - каждое действие в одну-две строки.

## Массивы

**Простыми словами:** массив - список покупок. Пункты идут по порядку, у каждого есть номер.

```js
const fruits = ["яблоко", "банан", "груша"];

console.log(fruits[0]);       // "яблоко"
console.log(fruits[2]);       // "груша"
console.log(fruits.length);   // 3
console.log(fruits[fruits.length - 1]); // "груша" - последний элемент
console.log(fruits[5]);       // undefined - такого элемента нет
```

| Понятие | Что это |
| --- | --- |
| `[ ... ]` | Массив: значения через запятую |
| Элемент | Одно значение в массиве |
| Индекс | Номер элемента. **Счёт с нуля**: первый - `0`, последний - `length - 1` |
| `length` | Количество элементов |

В массиве могут лежать значения любых типов, но обычно - одного: только числа, только строки, только объекты.

```js
const scores = [92, 78, 65, 88];
const empty = [];
```

### Перебор массива

`for...of` из урока 4 работает и с массивами:

```js
const scores = [92, 78, 65, 88];
let sum = 0;

for (const score of scores) {
    sum += score;
}

console.log(sum / scores.length); // 80.75
```

## Изменение и поиск

```js
const cart = ["хлеб", "молоко"];

cart.push("сыр");      // добавить в конец → ["хлеб", "молоко", "сыр"]
cart.pop();            // убрать последний → ["хлеб", "молоко"]
cart[0] = "батон";     // заменить по индексу → ["батон", "молоко"]

console.log(cart.includes("молоко")); // true
console.log(cart.indexOf("молоко"));  // 1
console.log(cart.indexOf("кефир"));   // -1 - не найдено
```

> **`const` и массив:** `const cart = [...]` запрещает положить в `cart` **другой** массив (`cart = []` - ошибка). Но менять содержимое того же массива - `push`, `pop`, `cart[0] = ...` - можно. Константа - это наклейка, приклеенная к одной коробке навсегда, а не запрет открывать коробку.

## Объекты

**Простыми словами:** объект - карточка в картотеке. У каждой строки карточки есть название и значение.

```js
const student = {
    name: "Анна",
    age: 15,
    isActive: true,
};

console.log(student.name);    // "Анна"
console.log(student["age"]);  // 15
```

| Понятие | Что это |
| --- | --- |
| `{ ... }` | Объект |
| Свойство | Пара `ключ: значение` |
| Ключ | Имя свойства: `name`, `age` |
| `student.name` | Чтение через точку - основной способ |
| `student["name"]` | Через скобки - когда имя свойства лежит в переменной |

Запятая после последнего свойства допустима и удобна: добавляя новую строку, не забудете поставить запятую.

### Изменение объекта

```js
const student = { name: "Анна", age: 15 };

student.age = 16;            // изменить
student.city = "Ташкент";    // добавить новое свойство
console.log(student);        // { name: "Анна", age: 16, city: "Ташкент" }
console.log(student.phone);  // undefined - такого свойства нет

const key = "name";
console.log(student[key]);   // "Анна" - имя свойства из переменной
```

### Вложенность

Значение свойства может быть массивом или другим объектом:

```js
const course = {
    title: "JavaScript",
    lessons: 10,
    author: { name: "Javlonbek", city: "Ташкент" },
    tags: ["язык", "DOM", "события"],
};

console.log(course.author.city);  // "Ташкент"
console.log(course.tags[1]);      // "DOM"
console.log(course.tags.length);  // 3
```

## Массив объектов

Самая частая форма данных - массив, где каждый элемент - объект с одинаковым набором свойств:

```js
const students = [
    { name: "Анна", score: 92 },
    { name: "Тимур", score: 78 },
    { name: "Лола", score: 65 },
    { name: "Сардор", score: 95 },
];

console.log(students[1].name);   // "Тимур"

for (const student of students) {
    console.log(`${student.name}: ${student.score}`);
}
```

Такую же структуру вы увидите в данных с сервера (урок 9) и будете выводить на страницу (урок 7).

## `map`, `filter`, `find`, `reduce`

Методы массивов принимают **функцию** и сами перебирают элементы. Удобнее всего передавать стрелочную функцию из урока 5.

### `map` - преобразовать каждый элемент

Возвращает **новый** массив той же длины:

```js
const names = students.map((student) => student.name);
console.log(names); // ["Анна", "Тимур", "Лола", "Сардор"]

const prices = [1000, 2500, 400];
const withTax = prices.map((price) => price * 1.12);
```

### `filter` - отобрать подходящие

Возвращает новый массив только с теми элементами, для которых функция вернула `true`:

```js
const excellent = students.filter((student) => student.score >= 90);
console.log(excellent.length); // 2
```

### `find` - найти первый подходящий

Возвращает **один элемент** или `undefined`, если ничего не нашлось:

```js
const timur = students.find((student) => student.name === "Тимур");
console.log(timur.score); // 78

const nobody = students.find((student) => student.name === "Ира");
console.log(nobody);      // undefined
```

### `reduce` - свести к одному значению

Проходит по массиву и копит результат - как накопитель из урока 4:

```js
const total = students.reduce((sum, student) => sum + student.score, 0);
console.log(total); // 330
```

| Часть | Что это |
| --- | --- |
| `sum` | Накопитель: результат предыдущего шага |
| `student` | Текущий элемент |
| `sum + student.score` | Новое значение накопителя |
| `0` | Начальное значение накопителя - **всегда указывайте** |

### Цепочки

Методы, которые возвращают массив, можно соединять:

```js
const topNames = students
    .filter((student) => student.score >= 90)
    .map((student) => student.name);

console.log(topNames); // ["Анна", "Сардор"]
```

| Метод | Возвращает | Исходный массив |
| --- | --- | --- |
| `map` | Новый массив той же длины | Не меняется |
| `filter` | Новый массив, возможно короче | Не меняется |
| `find` | Один элемент или `undefined` | Не меняется |
| `reduce` | Одно значение | Не меняется |
| `push` / `pop` | Длину / удалённый элемент | **Меняется** |

## Деструктуризация и `...`

### Деструктуризация - распаковать

```js
const student = { name: "Анна", score: 92 };
const { name, score } = student;
console.log(name, score); // Анна 92

const colors = ["red", "green", "blue"];
const [first, second] = colors;
console.log(first);       // "red"
```

Удобно в параметрах функции:

```js
const getLabel = ({ name, score }) => `${name} - ${score}`;
console.log(getLabel(student)); // Анна - 92
```

### Spread `...` - развернуть

```js
const a = [1, 2];
const b = [...a, 3];              // [1, 2, 3] - новый массив, a не изменился

const base = { name: "Анна", score: 92 };
const updated = { ...base, score: 95 };   // копия с новым score
console.log(base.score, updated.score);   // 92 95
```

**Зачем копировать?** Чистая функция не меняет входные данные. Если функция должна «добавить ученика», она возвращает новый массив `[...students, newStudent]`, а исходный остаётся прежним. Так проще находить ошибки: данные не меняются «за спиной».

| Задача | Запись |
| --- | --- |
| Массив / элемент / длина | `[1, 2]` / `arr[0]` / `arr.length` |
| Последний элемент | `arr[arr.length - 1]` |
| Добавить / убрать в конце | `arr.push(x)` / `arr.pop()` |
| Есть ли значение / индекс | `arr.includes(x)` / `arr.indexOf(x)` |

| Найти один | `arr.find((x) => условие)` |
| Свести к одному | `arr.reduce((acc, x) => ..., 0)` |
| Распаковать | `const { name } = obj;` |
| Копия с добавлением | `[...arr, x]`, `{ ...obj, key: value }` |

## Самостоятельная работа

### Часть 1. Задание в IDE (засчитывается платформой)

Платформа задаёт массив `students` - объекты `{ name, score }`. Напишите **чистые** функции, которые ничего не меняют во входных данных:

1. `getAverage(list)` - средний балл, округлённый через `Math.round`. Для пустого массива - `0`.
2. `getExcellentNames(list)` - массив **имён** учеников с баллом 90 и выше.
3. `findStudent(list, name)` - объект ученика с таким именем или `undefined`.
4. `addStudent(list, name, score)` - **новый** массив с добавленным учеником `{ name, score }`; исходный массив не меняется.

Используйте методы массивов: `reduce`, `filter`, `map`, `find` и spread `...`.

Что проверяет платформа: результаты функций на заданном и других массивах, включая пустой; `getExcellentNames` возвращает строки, а не объекты; `addStudent` не меняет исходный массив; использованы `reduce`, `filter`, `map`, `find` и `...`.

## Ответы

**Повторение**

1. `return` отдаёт значение программе, `console.log` только показывает его.
2. `const half = (n) => n / 2;`.
3. Функция, результат которой зависит только от аргументов и которая ничего не меняет снаружи.

**Мини-задание 1**

```js
const product = {
    title: "Ноутбук",
    price: 5000000,
    inStock: true,
};

product.price = product.price * 1.1;
product.category = "Техника";

console.log(`${product.title}: ${Math.round(product.price)} сум, в наличии: ${product.inStock}`);
// Ноутбук: 5500000 сум, в наличии: true
```

`Math.round` здесь - на всякий случай: при умножении на дробь результат может получиться с «хвостом», как `0.1 + 0.2` в уроке 2 (например, `1000 * 1.15` даёт `1150`, а `7 * 1.1` - `7.700000000000001`).

**Мини-задание 2**

```js
const products = [
    { title: "Ручка", price: 3000, inStock: true },
    { title: "Тетрадь", price: 8000, inStock: false },
    { title: "Линейка", price: 5000, inStock: true },
];

const available = products.filter((product) => product.inStock);
const titles = available.map((product) => product.title);
const total = available.reduce((sum, product) => sum + product.price, 0);

console.log(titles, total); // ["Ручка", "Линейка"] 8000
```

**Вопросы для самопроверки**

1. `0` и `4`.
2. `undefined`.
3. `const` запрещает переназначить переменную, но не менять содержимое массива.
4. Через точку - когда имя свойства известно заранее; через скобки - когда оно в переменной.
5. `map` преобразует каждый элемент (та же длина), `filter` оставляет только подходящие.
6. `undefined`.
7. Это стартовое значение накопителя; без него для пустого массива будет ошибка, а результат может оказаться неожиданным.
8. `map` и `filter` - нет, они возвращают новый массив. `push` - да.
9. Создаёт константу `name` со значением `student.name`.
10. `const next = [...arr, item];`.
