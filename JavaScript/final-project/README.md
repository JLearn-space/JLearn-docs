# Итоговый проект курса JavaScript

Готовый пример к [уроку 10](../Lesson-10/ru/Итоговый%20проект%20-%20интерактивный%20сайт.md): сайт кружка из двух страниц с четырьмя обязательными функциями. Это **образец для сверки**, а не заготовка: свой проект вы делаете на сайте из курсов HTML и CSS.

| Функция | Файл | Страница |
| --- | --- | --- |
| Мобильное меню, Escape, возврат фокуса | [js/menu.js](final/js/menu.js) | Все |
| Тема с сохранением в `localStorage` | [js/theme.js](final/js/theme.js) | Все |
| События из `data/events.json` с фильтром и тремя состояниями | [js/events.js](final/js/events.js) | [index.html](final/index.html) |
| Форма с проверкой и доступными ошибками | [js/form.js](final/js/form.js) | [contact.html](final/contact.html) |

Точка входа - [js/main.js](final/js/main.js): ставит класс `js` на `<html>` и вызывает функции `init...`. Каждая функция сама проверяет, есть ли её элементы на странице.

## Как запустить

Модули и `fetch` не работают при открытии файла двойным кликом. Откройте папку `final` в VS Code и запустите **Live Server** или выполните в этой папке:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Что проверить

Пройдите чек-лист приёмки из урока 10: консоль без ошибок, клавиатура, сохранение темы, каждая кнопка фильтра, ошибки формы, работа без JavaScript (DevTools → Disable JavaScript) и ширина 375 px.
