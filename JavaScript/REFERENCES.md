# Источники / References / Manbalar

Основные технические источники для проверки курса. Ссылки нужны для уточнения деталей; чтение полной спецификации не является заданием для начинающего.

Primary sources used to check the course. Reading the full specification is not a beginner assignment.

Kursni tekshirish uchun asosiy texnik manbalar. Spetsifikatsiyani to‘liq o‘qish yangi o‘rganuvchi uchun topshiriq emas.

## Язык / Language / Til

- [ECMAScript Language Specification](https://tc39.es/ecma262/) — официальное описание языка / the official language definition / tilning rasmiy tavsifi.
- [MDN: JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) — справочник по урокам 1–6 / reference for lessons 1–6 / 1–6-darslar uchun ma’lumotnoma. Есть русская версия части страниц / partly available in Russian.
- [MDN: Equality comparisons](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Equality_comparisons_and_sameness) — почему `===` / why `===` / nima uchun `===`.
- [MDN: Truthy](https://developer.mozilla.org/en-US/docs/Glossary/Truthy) и [Falsy](https://developer.mozilla.org/en-US/docs/Glossary/Falsy) — урок 3 / lesson 3 / 3-dars.
- [MDN: Array](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) — `map`, `filter`, `find`, `reduce`.
- [MDN: JavaScript modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) — `import` / `export`, урок 10 / lesson 10 / 10-dars.

## Браузер / Browser / Brauzer

- [WHATWG DOM Standard](https://dom.spec.whatwg.org/) — дерево документа и события / document tree and events / hujjat daraxti va hodisalar.
- [WHATWG HTML: the script element](https://html.spec.whatwg.org/multipage/scripting.html#the-script-element) — `defer`, `type="module"`.
- [MDN: Introduction to events](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Events) — урок 8 / lesson 8 / 8-dars.
- [MDN: Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API) — `localStorage`.
- [MDN: Using Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — запросы, урок 9 / requests, lesson 9 / so‘rovlar, 9-dars.
- [MDN: Client-side form validation](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation) — проверка форм / form validation / formalarni tekshirish.

## Доступность и инструменты / Accessibility and tools / Qulaylik va vositalar

- [WAI-ARIA APG: Button](https://www.w3.org/WAI/ARIA/apg/patterns/button/) — почему `<button>`, а не `<div>` / why `<button>`, not `<div>`.
- [WAI-ARIA APG: Disclosure (accordion)](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) — `aria-expanded` для аккордеона и меню / for accordion and menu.
- [Chrome DevTools: Console](https://developer.chrome.com/docs/devtools/console) — консоль и сообщения об ошибках / console and error messages / konsol va xato xabarlari.
- [Chrome DevTools: Debug JavaScript](https://developer.chrome.com/docs/devtools/javascript) — точки останова / breakpoints / to‘xtash nuqtalari.
- [GitHub Pages: creating a site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) — публикация итогового проекта / publishing the final project / yakuniy loyihani nashr qilish.

Сайты могут менять адреса страниц и подписи интерфейса. Если ссылка не открывается, найдите страницу по названию на том же сайте.

Sites may move pages or rename interface labels. If a link breaks, search for the page title on the same site.

Saytlar sahifa manzillarini va interfeys yozuvlarini o‘zgartirishi mumkin. Havola ochilmasa, sahifani shu saytda nomi bo‘yicha qidiring.
