# Курс «JavaScript: за 10 уроков» / "JavaScript: in 10 lessons"

> Курс из **10 уроков** о языке программирования JavaScript: от первой строки в консоли до интерактивного сайта. Первая половина курса посвящена самому языку: переменным, условиям, циклам, функциям, массивам и объектам. Вторая половина учит работать со страницей: DOM, события, формы, хранение данных и запросы к серверу. В итоговом проекте студент оживляет сайт, построенный в курсах HTML и CSS.
>
> A **10-lesson** course on the JavaScript programming language: from the first line in the console to an interactive website. Lessons 1–5 cover the language itself, lessons 6–9 the browser (DOM, events, forms, storage, fetch), and lesson 10 brings the HTML + CSS final project to life.

## Перед началом

Нужны курсы [«HTML: за 10 уроков»](https://github.com/JLearn-space/JLearn-docs/tree/main/HTML) и [«CSS: за 10 уроков»](https://github.com/JLearn-space/css): во второй половине курса JavaScript управляет HTML-страницей и её классами CSS, а итоговый проект продолжает сайт из этих курсов.

**Что понадобится:** компьютер, современный браузер (Chrome, Edge или Firefox) и редактор кода. Устанавливать Node.js не обязательно: весь код курса запускается в браузере.

**Как проходить урок:** прочитайте объяснение → выполните мини-задания в консоли → сделайте задание в IDE на платформе → проект на компьютере → тест урока. Урок засчитывается, когда задание в IDE прошло все автоматические тесты, а тест сдан от 70%.
