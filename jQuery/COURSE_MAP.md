## Принципы курса

- jQuery подключается **полной** сборкой 4.1.0 перед своим скриптом: `<script src="https://code.jquery.com/jquery-4.1.0.min.js"></script>` и `<script src="js/main.js" defer></script>`. В slim-сборке нет эффектов и AJAX.
- Код запускается после разбора HTML: атрибут `defer` или `$(function () { ... })`. Запись `$(document).ready(...)` устарела и не используется.
- Переменная с jQuery-объектом начинается с `$`: `const $list = $("#course-list");`. Так сразу видно, где jQuery-объект, а где обычное значение.
- Переменные - `const`, а `let` - только если значение меняется. `var` не используется. Сравнение - только `===` и `!==`.
- Текст выводится через `.text()`. `.html()` с данными пользователя не используется.
- Обработчики - через `.on()`. Сокращения `.click(fn)`, `.submit(fn)` и атрибуты `onclick=""` не используются.
- Внешний вид меняется классами (`addClass`, `toggleClass`). `.css()` - только для значений, которые вычисляются в коде.
- Удалённые в jQuery 4 функции не используются: вместо `$.trim` - `str.trim()`, вместо `$.isArray` - `Array.isArray`, вместо `$.parseJSON` - `JSON.parse`.
- Стиль записи: отступ 4 пробела, `;` в конце инструкции, имена в `camelCase`, строки в двойных кавычках.

## Практика на платформе

Задание в IDE - один JavaScript-файл. Платформа подключает jQuery 4.1.0 к странице задания, запускает код ученика и проверяет результат автоматическими тестами: состояние DOM после кликов и ввода, результаты функций, вывод в консоль. Подробно - [platform/README.md](platform/README.md).
